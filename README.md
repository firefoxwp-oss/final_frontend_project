# Separador de Contenido de Videos (Karaoke) — Frontend

Cliente web del sistema Separador de Contenido de Videos (Karaoke) potenciado por Machine Learning. Permite convertir canciones en pistas de karaoke desde el navegador.

## Funcionalidades

- Registro e inicio de sesión de usuarios.
- Gestión de proyectos.
- Subida de videos o audios para su procesamiento.
- Seguimiento del avance del procesamiento.
- Reproducción del video karaoke y de las pistas de audio.
- Historial de procesamientos y descarga de los resultados.

## Tecnologías

React, TypeScript, Vite y Tailwind CSS.
